# IntelTrace OSINT Platform

An educational Open Source Intelligence (OSINT) framework built for researchers, cybersecurity students, and digital investigators.

## Features
- **Username Enumeration:** Sweep 6+ social media platforms.
- **Image Forensics:** Extract GPS and camera EXIF data.
- **Domain Intelligence:** Generate simulated WHOIS reports.
- **IP Geolocation:** Live mapping of IP address origins.

## Disclaimer
This project is for **EDUCATIONAL USE ONLY**.
