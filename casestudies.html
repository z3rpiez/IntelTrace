OSINT in Action

Three educational scenarios demonstrating how open-source intelligence techniques are applied to real investigative challenges.

CASE STUDY 01

Tracking a Suspicious Username

USERNAME FINDER CROSS-PLATFORM
Difficulty: BEGINNER
Duration: ~15 minutes

A cybersecurity researcher receives a report about a user with the handle @shadow_exec who has been posting threatening messages. The user claims to have no other online presence.

Objective: Determine whether shadow_exec maintains accounts on other major platforms.

STEP 01
Username Enumeration

Input shadow_exec into IntelTrace's Username Finder.

STEP 02
Profile Discovery

Results show the username is FOUND on GitHub and Reddit. The Reddit account has 4 years of posting history.

Outcome: The cross-platform presence contradicted the user's claim.

Key Lessons: People often reuse usernames across platforms, leaving a trail of metadata over time.

CASE STUDY 02

Uncovering Location from a Photo

IMAGE METADATA EXIF FORENSICS
Difficulty: INTERMEDIATE
Duration: ~5 minutes

A journalist is investigating a whistleblower who posted an anonymous image claiming to be taken inside a classified facility.

Objective: Extract metadata embedded in the file to verify the claimed time and location.

STEP 01
EXIF Extraction

The file is uploaded to IntelTrace's Image Metadata Analyzer.

STEP 02
Data Analysis

Results reveal GPS coordinates in San Francisco. The claimed location does not match.

Outcome: The EXIF data proved the image was falsified.

Key Lessons: Smartphones embed GPS coordinates in original photos by default.

CASE STUDY 03

Investigating a Phishing Domain

DOMAIN INTEL IP ANALYSIS
Difficulty: ADVANCED
Duration: ~30 minutes

A corporate security analyst receives a phishing report about paypa1-secure-login.com.

Objective: Use domain intelligence and IP geolocation to map the phishing infrastructure.

STEP 01
Domain Registration Analysis

The Domain Intelligence tool reveals the domain was registered just 3 days ago.

STEP 02
IP Geolocation

IP Analysis reveals the server is hosted by a known offshore VPS provider.

Outcome: The domain was reported to ICANN and taken down.

Key Lessons: Registration date is a key indicator — most phishing domains are less than 30 days old.
